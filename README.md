# Viora 💜

**Viora – A Flutter-Based Real-Time Chat Application**

Viora is a modern messaging application built using Flutter and Supabase. It aims to provide a smooth, elegant, and user-friendly communication experience.

## ✨ Features

- User Authentication
- User Profiles
- Real-Time Messaging
- Chat Interface
- Supabase Backend Integration
- Elegant and Modern UI
- Image and Media Sharing

## 🛠️ Technologies Used

- Flutter
- Dart
- Supabase
- PostgreSQL
- Android Studio

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/viora.git
```

### 2. Open the Project

```bash
cd viora
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Configure Environment Variables

Create a `.env` file in the project root using `.env.example` as a template.

Add your own Supabase configuration locally.

### 5. Run the Application

```bash
flutter run
```

## 🔐 Security

- Never commit `.env` files.
- Never expose Supabase secret or service-role keys.
- Keep your credentials private.
