# Calling setup

Calls use `flutter_webrtc` for audio/video and Supabase Realtime/Postgres for call signaling. Apply migrations through `0009_call_followups.sql` before calling. Voice/video buttons work in direct conversations; group calls are not implemented. Calls that ring for 45 seconds are recorded as missed, and call history is available in Settings. Incoming calls appear in the in-app notification inbox while Viora is open. The built-in public STUN server is only a development default. Reliable production calls require a TURN server; issue short-lived TURN credentials from a protected Supabase Edge Function and never commit them in the client. Test call media on two real devices and different networks before relying on it; this project has not verified a live peer-to-peer call yet.
